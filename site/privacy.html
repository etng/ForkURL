ForkURL 隐私说明

ForkURL 用于把当前页面 URL 匹配为相关工具入口。扩展会在浏览器本地读取当前标签页 URL、规则配置和启停状态来生成跳转列表，但不会把这些内容发送到 ForkURL 的遥测服务。

本地处理

当前页面 URL 只用于本地正则匹配；自定义规则、远程规则地址、禁用状态和图标缓存保存在浏览器本地存储。启用远程规则源时，浏览器会向你配置的公开 URL 请求规则 JSON。

匿名使用统计

匿名使用统计默认开启，可在扩展设置页关闭。统计用于了解活跃安装量、版本分布和核心入口使用情况。

会发送的信息：

  • 匿名安装 ID 随机生成，仅用于区分安装，不包含账号或设备身份；服务端只保存不可逆哈希用于去重统计。
  • 扩展版本 例如 2.0.1，用于判断版本分布。
  • 事件类型 install、update、daily_active、popup_open、jump_open、options_open、rules_refresh。
  • 粗粒度环境 扩展语言、浏览器大类、操作系统大类。
  • 粗粒度来源 Cloudflare 提供的国家/地区码；不保存 IP、URL、域名或 referrer。
  • 日期 按 UTC 日期聚合，客户端会限频发送。

不会发送的信息：

  • 页面 URL 不会上传当前页面 URL、域名、路径、查询参数或 referrer。
  • 规则与跳转目标 不会上传匹配到的规则、生成的目标 URL、自定义规则或禁用状态。
  • 用户配置内容 不会上传导入导出的配置文件、远程规则地址或图标缓存内容。

Iconify 在线图标搜索

Iconify 搜索默认关闭。开启后，图标选择器会向 Iconify 服务请求搜索结果；选中的图标会缓存在本地。ForkURL 遥测不会记录图标搜索词。

关闭方式

打开 ForkURL 设置页，关闭“发送匿名使用统计”。关闭后扩展不会继续发送遥测请求，并会清理本地遥测 ID 与发送记录。

Chrome Web Store 用户数据政策

通过 Google API 获得的信息会遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。

反馈

反馈问题请使用 GitHub Issues 。提交问题时请先脱敏示例 URL 和配置。
